# HTTP-Only Learn

Simple README for this repository.

This project demonstrates a backend (Django) and a frontend (Angular) setup used to learn about HTTP-only tokens and related auth flows.

Structure
- backend/: Django app and API
- frontend/: Angular app
- Docs1.MD: additional docs

Quick start

Backend
1. Open a terminal in `backend/`
2. Install dependencies (e.g. `pip install -r requirements.txt` or use your virtualenv/poetry)
3. Run migrations and start the Django server:
   - `python manage.py migrate`
   - `python manage.py createsuperuser` (optional)
   - `python manage.py runserver`

Frontend
1. Open a terminal in `frontend/`
2. Install dependencies: `npm install`
3. Start dev server: `npm start` or `npm run start`

Notes
- See `Docs1.MD` for more detailed notes.
